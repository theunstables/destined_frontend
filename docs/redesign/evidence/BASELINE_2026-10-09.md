- Added an accessible polite announcement for the in-place A07 Reset Link Sent state.
- Added source tests asserting alert semantics for A05/A06/A09 request failures.

	the cleared password field with its error border and alert semantics, while
	network failures remain form-level alerts and the email stays populated.
- Added the first feature contract at `docs/redesign/contracts/AUTH.md`.
- Corrected A04 resend to submit the signed-in email instead of `email: ''`.

	`/auth/me` and advances only when the backend reports `emailVerified: true`;
	mock showcase mode retains manual continuation because it has no mail server.
- Added an A04 missing-session guard and regression test so resend can never
	fall back to an empty email payload.

	the local session verified and advances instead of displaying a dead-end
	error; a source regression test covers the branch.
- Completed A08's approved “Return to Sign In” action and added a polite live
	announcement for its in-place success state.
- Added HTTP auth-adapter source tests covering token storage after sign-up,
	`/auth/me` session refresh, credential cleanup after reset, and local cleanup
	even when server logout fails.
- Completed HTTP auth-adapter source coverage for sign-in, sign-up, recovery,
	reset, resend, current-session, error mapping, and logout. Added transport
	coverage proving public auth requests neither hydrate nor attach bearer state.

	no longer trigger refresh-token rotation before attempting revocation.
